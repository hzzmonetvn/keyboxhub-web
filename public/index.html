    Tài Liệu API & Tích Hợp
    
            
    Kết nối Keybox Hub với script, module Magisk, KernelSU, TrickyStore hoặc Kaorios Toolbox.
    
          
    
        
    

        
    
          
    
            
    
              
    
                GET
                /api/download
              
    
              Tải ngẫu nhiên 1 file keybox.xml khả dụng (Ưu tiên Strong → Device)
            
    
            
    # Tải file mặc định (Ưu tiên Strong RKP):
curl -L -o keybox.xml https://keybox.hzzmonet.io.vn/api/download

# Tải theo Profile RKP hoặc Hardware OEM:
curl -L -o keybox_rkp.xml "https://keybox.hzzmonet.io.vn/api/download?profile=rkp"
curl -L -o keybox_hw.xml "https://keybox.hzzmonet.io.vn/api/download?profile=hw"
    
          
    

          
    
            
    
              
    
                GET
                /api/status
              
    
              Thống kê trạng thái và danh sách metadata keybox (profile, rkp, certs)
            
    
            
    curl https://keybox.hzzmonet.io.vn/api/status
    
          
    

          
    
            
    
              
    
                POST
                /api/repair
              
    
              Sửa lỗi & chuẩn hóa keybox (sắp xếp chuỗi cert, bổ sung Google Root, ngắt dòng 64 ký tự PEM)
            
    
            
    curl -F "file=@broken_keybox.xml" "https://keybox.hzzmonet.io.vn/api/repair?download=true" -o keybox_repaired.xml
    
          
    

          
    
            
    
              
    
                POST
                /api/upload
              
    
              Upload đơn lẻ, nhiều file, ZIP hoặc qua link URL
            
    
            
    curl -F "files=@my_keybox.xml" https://keybox.hzzmonet.io.vn/api/upload
