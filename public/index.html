    Tài Liệu API & Hướng Dẫn Tích Hợp
    
            
    
              Tích hợp vào script bash, Cronjob, PlayIntegrityFix, TrickyStore
              hoặc module KernelSU/Magisk
            
    
          
    
        
    
        
    
          
    
            
    
              GET
              /api/download
              Tải ngẫu nhiên 1 file keybox.xml khả dụng (Ưu tiên Strong
                → Device)
            
    
            
    curl -L -o keybox.xml https://keybox.hzzmonet.io.vn/api/download
    
          
    

          
    
            
    
              POST
              /api/loot
              Kích hoạt fetch nguồn bên thứ 3 và tự động loot key Strong (bỏ
                qua trùng)
            
    
            
    curl -X POST https://keybox.hzzmonet.io.vn/api/loot
    
          
    

          
    
            
    
              POST
              /api/upload
              Upload đơn lẻ, nhiều file, ZIP hoặc qua link URL (Tự bỏ qua
                trùng lặp)
            
    
            
    # 1. Upload qua đường link trực tiếp (URL):
curl -X POST -H "Content-Type: application/json" -d '{"url": "https://example.com/keybox.xml"}' https://keybox.hzzmonet.io.vn/api/upload

# 2. Upload file nén ZIP hoặc file XML:
curl -F "files=@my_keyboxes.zip" https://keybox.hzzmonet.io.vn/api/upload
    
          
    

          
    
            
    
              GET
              /api/status
              Kiểm tra trạng thái hệ thống (strong / device / banned)
            
    
            
    curl https://keybox.hzzmonet.io.vn/api/status
    
          
    

          
    
            
    
              POST
              /api/report
              Báo cáo key bị hạ cấp xuống Device (trên 5 phiếu chuyển sang device)
            
    
            
    curl -X POST -H "Content-Type: application/json" -d '{"id": 1}' https://keybox.hzzmonet.io.vn/api/report
    
          
    

          
    
            
    
              POST
              /api/repair
              Sửa lỗi & chuẩn hóa keybox (sắp xếp chuỗi cert, bổ sung Google Root, ngắt dòng 64 ký tự PEM)
            
    
            
    # 1. Gửi file bị lỗi và nhận lại keybox.xml chuẩn hóa:
curl -F "file=@broken_keybox.xml" "https://keybox.hzzmonet.io.vn/api/repair?download=true" -o keybox_repaired.xml

# 2. Gửi raw XML và nhận JSON chẩn đoán kèm danh sách lỗi đã sửa:
curl -X POST -H "Content-Type: application/xml" --data-binary @broken.xml https://keybox.hzzmonet.io.vn/api/repair
